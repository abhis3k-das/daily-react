- `index.html` is the browser entry point. It provides the root element and loads `/src/main.tsx`.
- `src/` contains the React application source code.
- `public/` contains static assets referenced by root-relative URLs such as `/logo.png`. Vite copies them unchanged and does not add content hashes.
- `src/assets/` contains assets imported by source files. Vite processes them and normally adds content hashes during production builds for cache busting.
- `node_modules/` contains installed project dependencies and is populated by `npm install`.
- `package.json` defines project metadata, scripts, and allowed dependency versions.
- `package-lock.json` records the resolved dependency tree and exact installed versions. It should be committed to Git.
- `dist/` contains the deployable production build generated by `npm run build`. `npm run preview` serves it locally for verification.
